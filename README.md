Lantern Crossroads — a 3-lane dueling card game. Two lantern-keepers duel at dusk across three lanes (Dawn, Dusk, Night). Play spirit cards into lanes, resolve each lane at the end of the round, and darken two enemy lanterns to win. Cards combine through five abilities (Ember, Spark, Guard, Bloom, Anchor), and an AI rival reads the table and counters your plays.

## Run it

```sh
python3 -m http.server --directory game 8080
# then open http://localhost:8080 in a desktop browser
```
